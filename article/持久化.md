# 持久化

## 含义

在 Java 语境里，所谓的 持久化（Persistence） 指的是：
把程序运行时的对象或数据 长期保存 到某种存储介质（通常是数据库、文件系统），以便在程序结束后还能再次读取和使用。

## 核心概念

- 理解它在 Web 请求链路中的位置。
- 关注协议、状态、编码、性能和安全边界。
- 结合真实项目排查请求失败、响应慢、会话丢失等问题。

## 使用场景

对象持久化  
将 Java 对象的状态保存到数据库或文件中，下次运行时可以恢复成同样的对象。

数据持久化  
程序运行时产生的数据不会因为 JVM 退出而丢失，而是写入磁盘、数据库或其他外部存储。

持久层  
在分层架构中，持久层（Persistence Layer）负责与数据库交互，通常通过 DAO（Data Access Object）或 ORM 框架实现。


## 常见实现方式

JDBC  
最基础的方式，直接用 SQL 操作数据库。

ORM 框架  
如 Hibernate、MyBatis、JPA，把对象和数据库表映射起来，简化持久化操作。

序列化  
使用 Serializable 接口把对象转成字节流，保存到文件或传输到网络。

## 总结

在 Java 中，持久化就是让数据“活得更久”，不随着程序结束而消失。它是企业级开发的核心环节，保证数据的可靠性和可复用性。
