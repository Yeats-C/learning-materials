# JSON 指的是什么

## 📌 [JSON](ca://s?q=JSON是什么)
- 全称 **JavaScript Object Notation**，是一种轻量级的数据交换格式。  
- 基于 **键值对** 的结构，易于人类阅读和编写，同时也易于机器解析和生成。  
- 常用于 **前后端数据传输**，尤其是在 Web 应用和 API 通信中。

## 🔎 核心特性
- **[轻量化](ca://s?q=JSON轻量化特点)**：相比 XML 更简洁，数据体积小。  
- **[可读性强](ca://s?q=JSON可读性特点)**：语法简单，结构清晰。  
- **[跨语言支持](ca://s?q=JSON跨语言支持)**：几乎所有编程语言都有 JSON 解析库。  
- **[与 JavaScript 天然兼容](ca://s?q=JSON与JavaScript兼容性)**：JSON 格式源于 JavaScript 对象表示法，前端处理非常方便。  

## 📊 基本语法示例
```json
{
  "name": "Alice",
  "age": 25,
  "isStudent": false,
  "skills": ["Java", "Python", "JavaScript"]
}
```

对象：用 {} 包裹，包含键值对。

数组：用 [] 表示，存放多个值。

值类型：支持字符串、数字、布尔值、对象、数组和 null。

## 📊 总结
JSON 是一种通用的数据表示和交换格式。

在 Web 开发、API 通信、配置文件 等场景中广泛使用。

它的优势在于 简洁、跨平台、易解析，已经成为现代互联网应用的标准数据格式。
