# 模板引擎指的是什么

## 📌 [定义](ca://s?q=模板引擎定义)
- **模板引擎**（Template Engine）是一种用于 **分离数据与表现层** 的工具。  
- 它允许开发者在模板文件中定义页面结构和样式，然后通过引擎将数据填充进去，生成最终的页面或文档。  
- 常用于 **Web 开发**，例如生成 HTML 页面。  

---

## 📌 [工作原理](ca://s?q=模板引擎工作原理)
模板引擎的基本流程：  
1. **编写模板**：开发者定义页面结构，使用占位符表示动态数据。  
2. **传入数据**：程序将实际数据传递给模板引擎。  
3. **渲染输出**：模板引擎将数据填充到模板中，生成最终的 HTML 或其他格式。  

---

## 📌 [常见模板引擎](ca://s?q=常见模板引擎)
- **JSP/Servlet 中的 JSTL、EL**  
- **Freemarker**（Java 常用）  
- **Thymeleaf**（Spring 框架常用）  
- **Velocity**（早期 Java 模板引擎）  
- **Handlebars、Mustache**（JavaScript 常用）  
- **EJS、Pug**（Node.js 常用）  

---

## 🔎 核心特点

| 特性 | **[模板引擎](ca://s?q=模板引擎特点)** |
|------|--------------------------------|
| **作用** | 分离数据与视图，提升开发效率 |
| **优点** | 代码复用、结构清晰、易维护 |
| **常见场景** | Web 页面渲染、邮件生成、文档生成 |
| **代表工具** | Freemarker、Thymeleaf、Handlebars |

---

## 💡 总结
- 模板引擎的核心思想是 **数据与表现分离**。  
- 开发者只需维护模板结构，数据由程序动态传入。  
- 在 Web 开发中，它极大提高了 **代码复用性、可维护性和开发效率**。
