# 序列化与反序列化指的是什么

## 📌 序列化
- **序列化**（Serialization）是指将对象转换为 **字节序列** 的过程。  
- 主要用途：  
  - 便于对象在网络中传输。  
  - 将对象保存到文件或数据库中。  
- 在 Java 中，常通过实现 `Serializable` 接口来支持序列化。  

### 示例
```java
ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("data.obj"));
oos.writeObject(myObject); // 将对象序列化到文件
oos.close();
```

---

## 📌 反序列化
- **反序列化**（Deserialization）是指将字节序列恢复为 **对象** 的过程。  
- 主要用途：  
  - 从文件或网络中读取数据并还原为对象。  
- 在 Java 中，常通过 `ObjectInputStream` 来实现反序列化。  

### 示例
```java
ObjectInputStream ois = new ObjectInputStream(new FileInputStream("data.obj"));
MyClass obj = (MyClass) ois.readObject(); // 将字节序列反序列化为对象
ois.close();
```

---

## 🔎 核心区别

| 特性 | 序列化 | 反序列化 |
|------|--------|----------|
| **定义** | 对象 → 字节序列 | 字节序列 → 对象 |
| **用途** | 数据存储、网络传输 | 数据恢复、对象重建 |
| **Java 实现** | `ObjectOutputStream` | `ObjectInputStream` |

---

## 💡 总结
- **序列化**：将对象转为字节序列，便于存储和传输。  
- **反序列化**：将字节序列恢复为对象，便于使用和操作。  
- 它们是一对相反的过程，常用于 **分布式系统、缓存、持久化存储** 等场景。
