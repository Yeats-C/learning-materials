# Hibernate和MyBatis

## 概念

Hibernate和MyBatis 是 Java 后端常见框架或工具。学习框架时建议先理解它的设计目标和核心抽象，再掌握配置、扩展点、常见问题和项目落地方式。

框架能提升效率，但也会隐藏细节。遇到问题时要能回到基础层面分析：网络、线程、连接池、序列化、依赖版本、配置加载顺序和运行时日志。

## 学习重点

- 先理解核心模型，再看配置和扩展点。
- 区分框架默认行为和项目自定义行为。
- 排查问题时从日志、配置、依赖版本和运行环境入手。

## 使用场景

- 面试复习时，用于梳理概念、边界和常见追问。
- 项目开发时，用于判断技术选型、代码写法和排查方向。
- 线上问题处理时，用于快速定位相关模块和可能风险。

## 示例

```text
请求 -> 网关/服务器 -> Web框架 -> 业务服务 -> 数据访问 -> 响应
```

## 常见问题

- Hibernate 自动关联查询过多，引发 N+1 查询问题。
- MyBatis 手写 SQL 灵活但容易散落重复 SQL。
- 实体映射和数据库字段不一致，运行时才暴露问题。

## 总结

Hibernate和MyBatis 学习时要抓住核心抽象、默认约定和扩展点；项目使用时要补齐日志、监控、版本管理和故障预案。
