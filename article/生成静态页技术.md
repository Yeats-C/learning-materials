# 生成静态页技术指的是什么

## 📌 [定义](ca://s?q=生成静态页技术定义)
- **生成静态页技术**（Static Site Generation, SSG）是一种 **在构建阶段将页面预先生成静态 HTML 文件** 的技术。  
- 与动态渲染不同，静态页在用户访问时无需实时计算，直接返回预生成的 HTML。  
- 常用于 **博客、文档网站、企业官网** 等对性能和 SEO 要求较高的场景。  

---

## 📌 [工作原理](ca://s?q=生成静态页技术工作原理)
1. **编写内容**：开发者使用 Markdown、数据库或 CMS 提供数据。  
2. **模板渲染**：通过模板引擎或框架将数据与页面结构结合。  
3. **构建生成**：在构建阶段生成静态 HTML 文件。  
4. **部署发布**：将生成的静态文件部署到 Web 服务器或 CDN。  
5. **用户访问**：浏览器直接请求静态文件，响应速度快。  

---

## 📌 [常见框架](ca://s?q=静态页框架)
- **Jekyll**（Ruby 社区常用，GitHub Pages 默认支持）  
- **Hexo**（Node.js 社区常用，适合博客）  
- **Hugo**（Go 语言编写，构建速度快）  
- **Next.js**（React 框架，支持 SSG 与 SSR 混合）  
- **Nuxt.js**（Vue 框架，支持静态生成与服务端渲染）  

---

## 🔎 核心特点

| 特性 | **[静态页技术](ca://s?q=静态页技术特点)** |
|------|--------------------------------|
| **性能** | 页面预生成，响应速度快 |
| **安全性** | 无需数据库或后端逻辑，攻击面小 |
| **SEO 优势** | 静态 HTML 易于搜索引擎抓取 |
| **缺点** | 动态交互能力有限，需结合前端 JS 或 API |

---

## 💡 总结
- **生成静态页技术**通过在构建阶段生成 HTML 文件，提升了网站的性能与安全性。  
- 适合内容相对固定的网站，如 **博客、文档、企业官网**。  
- 在现代 Web 开发中，常与 **前端框架、API 服务** 结合，既保证性能又提供动态功能。
