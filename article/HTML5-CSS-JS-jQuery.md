# HTML5、CSS、原生 JS 与 jQuery

## 📌 [HTML5](ca://s?q=HTML5是什么)
- HTML 的第五个主要版本，是网页结构和内容的标准语言。  
- 新增了语义化标签（如 `<header>`、`<article>`）、多媒体支持（`<audio>`、`<video>`）、本地存储（localStorage、sessionStorage）、Canvas 绘图等。  
- 让网页更具交互性和可扩展性，减少对插件的依赖。

---

## 📌 [CSS](ca://s?q=CSS是什么)
- 层叠样式表，用来控制网页的样式和布局。  
- 可以定义颜色、字体、间距、动画、响应式布局等。  
- 现代 CSS 提供了 Flexbox、Grid 等强大的布局方式，使前端开发更高效。

---

## 📌 [原生 JavaScript](ca://s?q=原生JavaScript是什么)
- 浏览器内置的脚本语言，用来控制网页行为和交互。  
- 能操作 DOM（文档对象模型）、处理事件、与服务器通信（Ajax）、实现逻辑控制。  
- 不依赖任何库或框架，直接使用浏览器提供的 API。  
- 优点是轻量、灵活；缺点是需要开发者自己处理兼容性和复杂操作。

---

## 📌 [jQuery](ca://s?q=jQuery是什么)
- 一个流行的 JavaScript 库，封装了常用的 DOM 操作、事件处理、Ajax 请求和动画效果。  
- 提供简洁的语法，例如 `$("#id").hide()` 就能快速隐藏元素。  
- 优点是跨浏览器兼容性好、开发效率高；缺点是随着现代浏览器原生 API 的完善，使用率逐渐下降。  
- 在 2010 年前后非常流行，如今更多项目转向原生 JS 或现代框架（React、Vue、Angular）。

---

## 💡 总结
- **HTML5** → 定义网页结构和内容。  
- **CSS** → 控制网页样式和布局。  
- **原生 JS** → 提供网页交互逻辑和功能。  
- **jQuery** → 封装 JS 操作，简化开发。  

它们的关系可以理解为：**HTML5 是骨架，CSS 是外观，JS 是行为，jQuery 是 JS 的快捷工具。**
