# java.io包与IO体系

## 概念

java.io包与IO体系 属于 Java 输入输出体系。IO 的本质是程序和外部资源之间的数据交换，常见外部资源包括文件、网络、内存缓冲区和控制台。

学习时要区分字节/字符、节点流/处理流、阻塞/非阻塞、同步/异步。实际开发中还要关注编码、资源关闭、异常处理、缓冲区大小和大文件处理。

## 学习重点

- 区分字节流和字符流，理解缓冲流的作用。
- 文件操作要关注路径、编码、关闭资源和异常处理。
- 性能优化优先考虑缓冲、批量读写、减少系统调用和合适的并发模型。

## 使用场景

- 面试复习时，用于梳理概念、边界和常见追问。
- 项目开发时，用于判断技术选型、代码写法和排查方向。
- 线上问题处理时，用于快速定位相关模块和可能风险。

## 常见问题

- 字节流和字符流边界不清，二进制文件被当文本处理。
- 处理流和节点流混用后关闭责任不明确。
- 没有统一编码策略，跨平台读写结果不一致。

## 总结

java.io包与IO体系 的关键是数据如何流动、资源如何关闭、编码如何统一、数据量变大后如何保持稳定。
