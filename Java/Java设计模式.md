# Java 设计模式指的是什么

## 📌 [定义](ca://s?q=Java设计模式定义)
- **设计模式**是软件开发中总结出的 **可复用的解决方案**，用于应对常见的设计问题。  
- 在 Java 中，设计模式帮助开发者编写 **结构清晰、可维护、可扩展** 的代码。  
- 设计模式不是代码片段，而是一种 **设计思想与最佳实践**。  

---

## 📌 [设计模式分类](ca://s?q=Java设计模式分类)
Java 中常见的设计模式分为三大类：  
1. **创建型模式**：关注对象的创建过程。  
   - 单例模式（Singleton）、工厂方法（Factory Method）、抽象工厂（Abstract Factory）、建造者（Builder）、原型（Prototype）。  
2. **结构型模式**：关注类与对象的组合。  
   - 适配器（Adapter）、装饰器（Decorator）、代理（Proxy）、组合（Composite）、桥接（Bridge）、外观（Facade）、享元（Flyweight）。  
3. **行为型模式**：关注对象之间的交互与职责分配。  
   - 策略（Strategy）、观察者（Observer）、责任链（Chain of Responsibility）、命令（Command）、状态（State）、模板方法（Template Method）、迭代器（Iterator）、中介者（Mediator）、备忘录（Memento）、解释器（Interpreter）、访问者（Visitor）。  

---

## 📌 [常见应用场景](ca://s?q=Java设计模式应用场景)
- **单例模式**：数据库连接池、日志管理器。  
- **工厂模式**：对象创建与依赖注入。  
- **观察者模式**：事件监听机制（如 GUI、消息队列）。  
- **策略模式**：算法选择（如支付方式、排序策略）。  
- **代理模式**：AOP、远程调用、缓存代理。  

---

## 🔎 核心特点

| 类别 | **作用** | **常见模式** |
|------|----------|--------------|
| **创建型** | 解决对象创建问题 | 单例、工厂、建造者 |
| **结构型** | 解决类与对象组合问题 | 适配器、代理、装饰器 |
| **行为型** | 解决对象交互与职责分配问题 | 策略、观察者、命令 |

---

## 💡 总结
- **Java 设计模式**是开发者在实践中总结出的 **通用解决方案**。  
- 三大类模式分别解决 **对象创建、结构组合、行为交互** 的问题。  
- 合理使用设计模式能提升代码的 **可维护性、可扩展性与复用性**。  
- 它们是 **面向对象设计思想** 在 Java 中的具体体现。
