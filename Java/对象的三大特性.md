# 对象的三大特性

## 概念

面向对象的三大特性是封装、继承和多态。封装把数据和行为组织到对象内部，通过访问控制隐藏实现细节；继承用于复用和扩展父类能力；多态允许父类引用指向子类对象，从而在运行期表现出不同实现。

封装提升可维护性，继承提升复用但可能带来强耦合，多态提升扩展性，是接口编程和设计模式的基础。

## 常见问题

- 把继承当作复用首选，导致父子类强耦合。
- 封装只理解为 private 字段，没有控制对象状态一致性。
- 多态只停留在语法层面，没有结合接口和扩展点设计。

## 总结

封装保证对象自身一致性，继承表达稳定的 is-a 关系，多态支撑可扩展设计；三者要服务于低耦合和高内聚。
