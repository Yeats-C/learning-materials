# 方法的重写和重载

## 概念

方法的重写和重载 是 Java 面向对象基础中的重要知识点。学习时应重点理解它解决的问题、语法表现、运行时行为，以及它和封装、继承、多态之间的关系。

实际编码中，这类知识点会直接影响类的职责划分、对象创建方式、扩展方式和代码可维护性。不要只记语法，要结合业务对象、接口抽象和测试可读性一起理解。

## 学习重点

- 掌握核心概念和适用场景。
- 理解常见用法、边界条件和容易踩坑的地方。
- 结合代码或项目案例进行验证。

## 使用场景

- 面试复习时，用于梳理概念、边界和常见追问。
- 项目开发时，用于判断技术选型、代码写法和排查方向。
- 线上问题处理时，用于快速定位相关模块和可能风险。

## 示例

```java
// 示例：用一个最小入口观察当前知识点的运行方式。
public class Example {
    public static void main(String[] args) {
        System.out.println("learn " + Example.class.getSimpleName());
    }
}
```

## 常见问题

- 重载方法参数过于相似，调用方容易选错。
- 重写时放宽异常或降低可见性违反语言规则。
- equals 重写后没有同步重写 hashCode。

## 总结

方法的重写和重载 的重点不是语法本身，而是如何通过类、接口和对象关系表达稳定的业务模型，并让变化点有清晰承载位置。
