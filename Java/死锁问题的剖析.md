# 死锁问题的剖析

## 概念

死锁问题的剖析 属于 Java 并发编程的基础内容。并发问题通常不是语法问题，而是多个线程同时访问共享状态时产生的可见性、原子性和有序性问题。

学习时要结合线程生命周期、锁、等待唤醒、线程池、阻塞队列和异常处理理解。生产问题排查通常需要日志、线程 dump、CPU 使用率、锁等待和连接池状态一起分析。

## 学习重点

- 掌握核心概念和适用场景。
- 理解常见用法、边界条件和容易踩坑的地方。
- 结合代码或项目案例进行验证。

## 使用场景

- 面试复习时，用于梳理概念、边界和常见追问。
- 项目开发时，用于判断技术选型、代码写法和排查方向。
- 线上问题处理时，用于快速定位相关模块和可能风险。

## 常见问题

- 只看业务日志，不抓线程 dump，无法确认线程等待关系。
- 多个锁获取顺序不一致，低并发测试不容易暴露。
- 没有设置超时和降级策略，死锁后只能重启恢复。

## 总结

死锁排查的核心是找到锁等待环路；预防上要统一加锁顺序、缩小锁范围、使用超时锁并避免锁内调用外部资源。
