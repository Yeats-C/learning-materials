# Java 与 UML 建模指的是什么

## 📌 [Java](ca://s?q=Java是什么)
- **Java** 是一种广泛使用的 **面向对象编程语言**，具有跨平台、稳定、安全的特点。  
- 在软件开发中，Java 常用于 **企业应用、Web 系统、移动应用、分布式系统**。  
- 特点：  
  - 跨平台（一次编写，到处运行）。  
  - 面向对象（封装、继承、多态）。  
  - 丰富的类库与框架支持。  

---

## 📌 [UML 建模](ca://s?q=UML建模是什么)
- **UML（Unified Modeling Language，统一建模语言）** 是一种 **软件建模标准语言**。  
- 用于描述、可视化和设计软件系统的结构与行为。  
- 特点：  
  - 提供统一的符号与图形表示。  
  - 支持面向对象的分析与设计。  
  - 常用于系统需求分析、架构设计、文档编制。  

---

## 📌 [常见 UML 图](ca://s?q=UML图类型)
- **用例图（Use Case Diagram）**：描述系统功能与用户交互。  
- **类图（Class Diagram）**：描述类、属性、方法及类之间的关系。  
- **顺序图（Sequence Diagram）**：描述对象之间的交互顺序。  
- **活动图（Activity Diagram）**：描述业务流程或操作步骤。  
- **状态图（State Diagram）**：描述对象的状态变化。  

---

## 📌 [Java 与 UML 的关系](ca://s?q=Java与UML关系)
- UML 是 **建模工具**，帮助开发者在编码前设计系统结构。  
- Java 是 **实现工具**，将 UML 模型转化为实际代码。  
- UML 类图常用于生成 Java 类结构，顺序图用于指导方法调用逻辑。  
- 两者结合能提升 **软件开发的可视化、可维护性与团队协作效率**。  

---

## 🔎 核心特点

| 概念 | **作用** | **特点** | **应用场景** |
|------|----------|----------|--------------|
| **Java** | 编程语言 | 跨平台、面向对象 | 企业应用、Web 系统 |
| **UML** | 建模语言 | 可视化、标准化 | 系统分析、架构设计 |
| **结合** | 设计 + 实现 | UML 指导 Java 开发 | 大型软件工程 |

---

## 💡 总结
- **Java**：一种跨平台的面向对象编程语言，用于实现系统功能。  
- **UML**：一种统一建模语言，用于系统分析与设计。  
- 两者结合：UML 提供 **设计蓝图**，Java 负责 **代码实现**，共同提升软件开发的效率与质量。
