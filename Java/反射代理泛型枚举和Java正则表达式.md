# 反射、代理、泛型、枚举和Java正则表达式

## 概念

反射、代理、泛型、枚举和Java正则表达式 是 Java 进阶能力的组合。反射让程序在运行期检查和操作类信息；代理用于在不修改目标对象的情况下增强行为；泛型提升类型安全；枚举表达有限固定值；正则表达式用于文本匹配和提取。

这些能力很强，但也容易降低可读性或带来性能开销。使用时要让调用方仍然容易理解代码意图。

## 学习重点

- 掌握核心概念和适用场景。
- 理解常见用法、边界条件和容易踩坑的地方。
- 结合代码或项目案例进行验证。

## 使用场景

- 面试复习时，用于梳理概念、边界和常见追问。
- 项目开发时，用于判断技术选型、代码写法和排查方向。
- 线上问题处理时，用于快速定位相关模块和可能风险。

## 常见问题

- 反射绕过编译期检查，运行时才暴露错误。
- 动态代理只代理接口或类的限制没弄清楚。
- 泛型擦除导致运行期无法直接获取完整泛型信息。

## 总结

反射、代理、泛型、枚举和Java正则表达式 能增强框架能力和代码表达力，但越动态越要控制边界，避免让错误从编译期推迟到运行期。
