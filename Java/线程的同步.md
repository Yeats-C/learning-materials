# 线程的同步

## 概念

线程的同步 属于 Java 并发编程的基础内容。并发问题通常不是语法问题，而是多个线程同时访问共享状态时产生的可见性、原子性和有序性问题。

学习时要结合线程生命周期、锁、等待唤醒、线程池、阻塞队列和异常处理理解。生产问题排查通常需要日志、线程 dump、CPU 使用率、锁等待和连接池状态一起分析。

## 学习重点

- 理解线程安全产生的原因：共享数据、并发访问、非原子操作。
- 掌握 synchronized、Lock、volatile、CAS、线程池等基础工具。
- 排查并发问题时关注锁范围、等待关系、超时策略和线程 dump。

## 使用场景

- 面试复习时，用于梳理概念、边界和常见追问。
- 项目开发时，用于判断技术选型、代码写法和排查方向。
- 线上问题处理时，用于快速定位相关模块和可能风险。

## 示例

```java
// 示例：用一个最小入口观察当前知识点的运行方式。
public class Example {
    public static void main(String[] args) {
        System.out.println("learn " + Example.class.getSimpleName());
    }
}
```

## 常见问题

- 共享变量没有同步保护，偶发数据错乱难以复现。
- 锁范围过大，吞吐下降并放大下游慢调用影响。
- 异常没有在线程内处理，任务失败后主流程无感知。

## 总结

线程的同步 要围绕共享状态、线程协作和资源控制理解；能写出来只是第一步，能监控、能限流、能排查才适合生产使用。
