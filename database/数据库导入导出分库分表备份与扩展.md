# 数据库导入导出、分库分表、备份与扩展

## 概念

数据库导入导出、分库分表、备份与扩展 是数据库学习和项目开发中的核心知识点。数据库知识不能只看语法，还要结合数据建模、事务、索引、锁、执行计划、备份恢复和线上风险控制。

实际项目中，一个数据库设计或 SQL 写法可能同时影响正确性、性能和可维护性。处理数据库问题时应先确认业务语义，再看数据量、索引、事务边界和并发情况。

## 学习重点

- 先明确数据模型和查询场景，再设计表结构与索引。
- 关注事务边界、隔离级别、锁竞争和慢 SQL。
- 生产环境操作数据前要评估备份、回滚和影响范围。

## 使用场景

- 面试复习时，用于梳理概念、边界和常见追问。
- 项目开发时，用于判断技术选型、代码写法和排查方向。
- 线上问题处理时，用于快速定位相关模块和可能风险。

## 示例

```sql
-- 示例：先明确查询条件，再结合索引和执行计划优化
SELECT id, name
FROM example_table
WHERE status = 1
ORDER BY created_time DESC;
```

## 常见问题

- 导入导出没有校验行数、编码和约束状态。
- 分库分表只解决容量问题，没有处理跨分片查询和事务。
- 备份可用性没有定期恢复演练。

## 总结

数据库导入导出、分库分表、备份与扩展 要同时考虑正确性、性能和可恢复性；数据库问题通常不是单条 SQL 的问题，而是模型、事务、索引和数据量共同作用。
