# 事务ACID、隔离级别、锁和传播机制

## 概念

事务用于保证一组数据库操作要么全部成功，要么全部失败。ACID 分别是原子性、一致性、隔离性、持久性。隔离级别通常包括读未提交、读已提交、可重复读、串行化，不同级别会影响脏读、不可重复读和幻读。

锁是实现隔离的重要机制，常见有共享锁、排他锁、行锁、表锁、间隙锁。Spring 中事务传播机制决定一个方法调用另一个事务方法时如何加入、创建或挂起事务。

## 学习重点

- 先明确数据模型和查询场景，再设计表结构与索引。
- 关注事务边界、隔离级别、锁竞争和慢 SQL。
- 生产环境操作数据前要评估备份、回滚和影响范围。

## 常见问题

- 方法内部自调用事务方法，导致 Spring AOP 事务不生效。
- 长事务中夹杂远程调用，锁持有时间过长。
- 误以为可重复读能解决所有并发问题，忽略间隙锁和幻读差异。

## 总结

事务设计要控制边界和时长，隔离级别要结合数据库实现理解；Spring 传播机制解决调用链事务关系，但不能替代业务一致性设计。
